# 티어컵 알고리즘 설계

## 1. 개요

유저가 두 아이템 중 하나를 선택하면, 그 비교 결과를 바탕으로 모든 아이템의 티어를 실시간으로 계산합니다. 위상정렬 기반의 계층 시스템과 비율 기반 티어 매핑을 결합하여, 최소한의 비교로 골고루 분포된 티어 배치를 구현합니다.

---

## 2. 핵심 개념

### 2.1 비교 결과 저장 (방향 그래프)

유저가 A vs B에서 A를 선택하면 "A → B" 간선을 생성합니다.

- A → B: A가 B를 이겼다 (A가 B보다 위)
- 간선의 방향 = 승패 관계

```
비교 기록 예시:
A가 B를 이김 → A → B
C가 D를 이김 → C → D
A가 C를 이김 → A → C
```

### 2.2 계층 계산 (위상정렬 BFS)

indegree = 나를 이긴 아이템 수

**BFS 레벨로 계층 결정:**

- 0계층: 처음부터 indegree 0인 아이템들 (아무한테도 안 짐)
- 1계층: 0계층 제거 후 indegree 0이 된 아이템들
- 2계층: 1계층 제거 후 indegree 0이 된 아이템들
- ...반복

### 2.3 티어 구간

| 비율 | 티어 |
| --- | --- |
| ~15% | S |
| ~30% | A |
| ~50% | B |
| ~70% | C |
| ~85% | D |
| ~100% | F |

---

## 3. 실시간 티어 계산

매 비교 후, 다음 4단계를 거쳐 티어를 계산합니다.

### 3.1 1단계: 계층 계산 (위상정렬 BFS)

매 비교 후 전체 아이템의 계층을 다시 계산합니다.

### 3.2 2단계: 줄세우기

계층 순서대로 아이템을 나열합니다.

- 0계층 아이템들 → 1계층 아이템들 → 2계층 아이템들 → ...

### 3.3 3단계: 비율 계산

각 아이템의 비율을 계산합니다.

**공식:**

```
비율 = 순위 / 전체 인원
```

### 3.4 4단계: 티어 매핑

비율을 티어 구간에 매핑합니다.

| 비율 | 티어 |
| --- | --- |
| ~15% | S |
| ~30% | A |
| ~50% | B |
| ~70% | C |
| ~85% | D |
| ~100% | F |

---

## 4. 예시 (16개 아이템)

### 토너먼트 완료 후 계층

```
0계층: A (1명)
1계층: B, I (2명)
2계층: C, E, J, M (4명)
3계층: D, F, G, K, N, O (6명)
4계층: H, L, P (3명)
```

### 줄세우기 → 비율 → 티어

| 순위 | 아이템 | 비율 | 티어 |
| --- | --- | --- | --- |
| 1위 | A | 6.25% | S |
| 2위 | B | 12.5% | S |
| 3위 | I | 18.75% | A |
| 4위 | C | 25% | A |
| 5위 | E | 31.25% | B |
| 6위 | J | 37.5% | B |
| 7위 | M | 43.75% | B |
| 8위 | D | 50% | B |
| 9위 | F | 56.25% | C |
| 10위 | G | 62.5% | C |
| 11위 | K | 68.75% | C |
| 12위 | N | 75% | D |
| 13위 | O | 81.25% | D |
| 14위 | H | 87.5% | F |
| 15위 | L | 93.75% | F |
| 16위 | P | 100% | F |

### 최종 티어표

```
S │ A, B (2명)

C │ F, G, K (3명)
D │ N, O (2명)
F │ H, L, P (3명)
```

## 5. 비교 순서 알고리즘

### 5.1 1단계: 토너먼트 (n-1번 비교)

처음에는 토너먼트 방식으로 진행하여 전체 구조를 빠르게 파악합니다.

**8개 아이템 예시:**

```
1라운드 (4번 비교):
A vs B → A 승
C vs D → C 승
E vs F → E 승
G vs H → G 승

결과:
0계층: A, C, E, G
1계층: B, D, F, H
```

```
2라운드 (2번 비교):
A vs C → A 승
E vs G → E 승

결과:
0계층: A, E
1계층: B, C, F, G
2계층: D, H
```

```
3라운드 (1번 비교):
A vs E → A 승

결과:
0계층: A
1계층: B, C, E
2계층: D, F, G
3계층: H
```

### 5.2 2단계: 같은 계층 내 세분화

토너먼트 완료 후 같은 계층에 여러 아이템이 있으면 추가 비교합니다.

**규칙:**

- 같은 계층끼리 비교
- 이미 부모-자식 관계(방향 그래프에서 경로가 존재)인 쌍은 건너뜀
- 상위 계층 우선 정리 (하위 계층은 유저 관심도 낮음)

**예시 (1계층 정리):**

```
현재 상태:
0계층: A
1계층: B, C, E
2계층: D, F, G
3계층: H

B vs C → B 승 (B → C 추가)

새로운 상태:
0계층: A
1계층: B, E
2계층: C, F, G
3계층: D, H
```

## 7. 조기 종료 처리

유저가 [지금 결과 확정하기] 버튼을 누르면:

- 현재까지 계산된 계층과 비율로 티어 확정
- 비교되지 않은 아이템은 ? 티어로 표시
- 결과 페이지에서 ? 티어는 숨김 처리

## 8. 구현 요약

```
1. 유저가 A vs B에서 A 선택
2. 방향 그래프에 A → B 간선 추가
3. 위상정렬 BFS로 계층 계산
4. 계층 순서대로 줄세움
5. 순위 / 전체 인원 = 비율
6. 비율로 티어 매핑
7. UI 업데이트
8. 다음 비교 쌍 선택 (토너먼트 → 같은 계층 세분화)
9. 반복
```
