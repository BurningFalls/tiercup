# TierCup MVP PRD

## 핵심 정보

**목적**: 로그인 없이 누구나 아이템을 1:1 비교하여 위상정렬 기반 S~F 티어를 자동 생성하는 플랫폼
**사용자**: 게임, 음식, 콘텐츠 등 취향 비교를 즐기는 일반 사용자 및 티어컵을 제작해 공유하는 크리에이터

---

## 사용자 여정

```
1. 메인 페이지
   ↓ [+ 새 티어컵 만들기] 클릭

2. 새 티어컵 만들기 페이지
   ↓ 제목 + 아이템 입력 후 [만들기] 클릭

3. 티어컵 만들기 완료 페이지
   → 공유 링크 + 관리 링크 확인 및 복사

────────────────────────────────────────

1. 메인 페이지 / 전체 티어컵 페이지
   ↓ 티어컵 카드 클릭

2. 플레이 화면
   ↓ 두 아이템 클릭으로 1:1 비교 반복
   ↓ [지금 결과 확정하기] 또는 모든 비교 완료

3. 결과 페이지 (플레이 완료)
   ↓ [티어 수정] 클릭 → 결과 수정 페이지 (모드 전환)
   ↓ [다시하기] 클릭 → 플레이 화면
   ↓ [공유] 클릭 → 공유 링크 복사

────────────────────────────────────────

1. 공유 링크 접속
   ↓ 결과 페이지 (공유 링크)
   ↓ [나도 해보기] 클릭 → 플레이 화면

────────────────────────────────────────

1. 관리 링크 접속
   ↓ 티어컵 수정 페이지
   ↓ 제목/아이템 수정 또는 티어컵 삭제
```

## 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|---------------|------------|
| **F001** | 티어컵 생성 | 제목(최대 30자), 아이템 4~64개(이미지+이름) 입력으로 티어컵 생성. play_code + manage_code 발급 | 플랫폼 핵심 콘텐츠 공급 | 새 티어컵 만들기 페이지, 티어컵 만들기 완료 페이지 |
| **F002** | 1:1 비교 플레이 | 두 아이템을 클릭하여 비교. 0.3초 하이라이트 후 결과 저장 및 다음 쌍 표시. 사이드바에 실시간 티어 표시 | 서비스 핵심 인터랙션 | 플레이 화면 |
| **F003** | 위상정렬 티어 자동 계산 | 비교 결과를 방향 그래프로 저장, BFS 위상정렬로 계층 계산, 비율 기반으로 S~F 티어 매핑 | 핵심 알고리즘, 서비스 차별점 | 플레이 화면, 결과 페이지 |
| **F004** | 최적 비교 순서 결정 | 토너먼트 방식(n-1번)으로 비교 순서 생성, 같은 계층 내 세분화, 이미 관계 있는 쌍 건너뜀 | 최소 비교 횟수 보장 | 플레이 화면 |
| **F005** | 조기 종료 | [지금 결과 확정하기] 클릭 시 미비교 아이템 ? 티어로 저장하고 결과 페이지 이동 | 사용자 이탈 방지, 긴 티어컵 UX | 플레이 화면 |
| **F006** | 결과 확인 | 확정된 티어(S~F)만 표시, ? 티어 숨김. 비교 횟수/총 항목/소요 시간 통계 표시 | 플레이 완료 후 핵심 가치 전달 | 결과 페이지 (플레이 완료) |
| **F007** | 결과 수동 수정 | 드래그앤드롭으로 아이템 또는 티어 단위 이동 후 저장. 변경사항 있을 때 취소 시 확인 모달 | 알고리즘 결과 보정 허용 | 결과 수정 페이지 |
| **F008** | 결과 공유 | result_code 기반 공유 링크 생성 및 클립보드 복사. 공유 링크 접속 시 [나도 해보기] 표시 | 바이럴 확산 핵심 경로 | 결과 페이지 (플레이 완료), 결과 페이지 (공유 링크) |
| **F009** | 티어컵 공유 | play_code 기반 공유 링크 클립보드 복사 | 티어컵 확산 핵심 경로 | 메인 페이지, 전체 티어컵 페이지 |
| **F010** | 티어컵 목록 및 탐색 | 인기순/좋아요순/최신순 정렬, 12개씩 페이지네이션, 검색바 | 콘텐츠 발견 경로 | 메인 페이지, 전체 티어컵 페이지 |
| **F011** | 통계 조회 | 아이템별 티어 분포 히트맵, S/F티어 1위, 가장 치열한 대결, 전체 참여자/비교 횟수/평균 소요 시간 | 크리에이터와 사용자 재참여 유도 | 통계 페이지 |
| **F012** | 좋아요 | localStorage client_id 기반 좋아요 추가/취소. 중복 방지 | 인기 지표 생성, 정렬 기준 제공 | 메인 페이지, 전체 티어컵 페이지, 결과 페이지 (공유 링크) |
| **F013** | 티어컵 수정 및 삭제 | manage_code 접속으로 제목/아이템 수정, 아이템 추가/삭제, 티어컵 삭제 | 크리에이터 콘텐츠 관리 | 티어컵 수정 페이지 |

## 메뉴 구조

```
메인 내비게이션 (모든 사용자, 인증 불필요)
├── 홈
│   └── 기능: F010 (인기/좋아요/최신 각 4개 카드), F009 (공유), F012 (좋아요)

플레이 흐름 (URL 직접 접근)
├── 플레이 화면 (/play/:playCode)
│   └── 기능: F002, F003, F004, F005

│   └── 기능: F006, F007, F008, F012
├── 결과 페이지 - 공유 링크 (/result/:resultCode)
│   └── 기능: F006, F008, F012
├── 결과 수정 페이지 (/result/:resultCode, 수정 모드)
│   └── 기능: F007
└── 통계 페이지 (/stats/:playCode)
    └── 기능: F011

관리 흐름 (manage_code 보유자)
└── 티어컵 수정 페이지 (/manage/:manageCode)
    └── 기능: F013
```

## 주요 제약사항 및 가정

| 항목 | 내용 |
|------|------|
| **인증 없음** | 모든 API는 인증 없이 접근 가능. 권한은 play_code / manage_code / result_code URL 보유 여부로만 구분 |
| **좋아요 중복 방지** | localStorage UUID v4 기반 client_id 생성. DB의 UNIQUE(tier_cup_id, client_id)로 서버 측 중복 방지. 시크릿 모드/다른 브라우저 중복은 허용된 한계 |
| **이미지 저장** | Supabase Storage에 업로드, image_url은 CDN URL로 저장 |
| **위상정렬 실행 위치** | 서버(Route Handler)에서 실행하여 결과 반환. 클라이언트는 사이드바 표시만 담당 |
| **코드 생성** | nanoid 기반 충돌 가능성 최소화 (play_code 6자, manage_code 12자, result_code 6자) |
| **rate limiting** | 좋아요 API에 IP 기반 rate limiting 적용 (Upstash Ratelimit + Redis 또는 Supabase Edge Functions) |
| **아이템 이미지 형식** | JPG, PNG, GIF만 허용, 5MB 이하 |
| **티어컵 규모** | 아이템 최소 4개, 최대 64개. 예상 최대 비교 횟수: 64개 아이템 기준 73~75번 |
