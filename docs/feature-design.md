# 티어컵 기능 설계

> 노션 데이터베이스 원본: https://www.notion.so/302f6ba9bd67800da3bfe6dba31b806b

각 항목은 **종류** (화면 / 액션 / 예외), **항목**, **내용**으로 구성됩니다.

---

## 01. 메인 페이지

### 화면

| 항목 | 내용 |
|------|------|
| URL | / |
| 로드 데이터 | 인기 티어컵 4개, 좋아요 많은 티어컵 4개, 새로운 티어컵 4개 |
| 초기 상태 | 3개 섹션 각각 4개 카드 표시 |

### 액션

| 항목 | 내용 |
|------|------|
| TierCup 로고 클릭 | 메인 페이지 새로고침 |
| 티어컵 카드 클릭 | 해당 티어컵 플레이 화면으로 이동 |
| 티어컵 카드 통계 버튼 클릭 | 해당 티어컵 통계 페이지로 이동 |
| 티어컵 카드 공유 버튼 클릭 | 플레이 링크 클립보드 복사 + "링크가 복사되었어요!" 토스트 메시지 |
| 인기 티어컵 [더보기] 클릭 | 전체 티어컵 페이지 '🔥 인기순' 정렬이 선택된 페이지로 이동 |
| 사람들이 좋아한 티어컵 [더보기] 클릭 | 전체 티어컵 페이지 '❤️ 좋아요순' 정렬이 선택된 페이지로 이동 |
| 새로운 티어컵 [더보기] 클릭 | 전체 티어컵 페이지 '🆕 최신순' 정렬이 선택된 페이지로 이동 |
| [+ 새 티어컵 만들기] 클릭 | **새 티어컵 만들기 페이지**로 이동 |
| 검색바 입력 후 엔터 | 전체 티어컵 페이지로 이동 + 검색 결과 표시 |

### 예외

| 항목 | 내용 |
|------|------|
| 티어컵 목록 없음 | "아직 티어컵이 없어요. 첫 번째로 만들어보세요!" 표시 |
| 검색 결과 없음 | “검색 결과가 없어요” 표시 |
| API 오류 | “불러오는 중 문제가 생겼어요. 다시 시도해주세요.” 표시 |
| 썸네일 이미지 로드 실패 | 기본 플레이스홀더 이미지 표시 |
| 클립보드 복사 실패 | “복사에 실패했어요. 다시 시도해주세요.” 토스트 메시지 |

## 02. 전체 티어컵 페이지

### 화면

| 항목 | 내용 |
|------|------|
| URL | /explore?sort={popular,likes,recent} |
| 로드 데이터 | 정렬 기준에 맞는 티어컵 목록 (12개씩) |
| 초기 상태 | URL 파라미터에 맞는 정렬 탭 활성화, 1페이지 표시, 티어컵 총 개수 |

### 액션

| 항목 | 내용 |
|------|------|
| TierCup 로고 클릭 | 메인 페이지로 이동 |
| 티어컵 카드 클릭 | 해당 티어컵 플레이 화면으로 이동 |
| 티어컵 카드 통계 버튼 클릭 | 해당 티어컵 통계 페이지로 이동 |
| 티어컵 카드 공유 버튼 클릭 | 플레이 링크 클립보드 복사 + "링크가 복사되었어요!" 토스트 메시지 |
| [+ 새 티어컵 만들기] 클릭 | **새 티어컵 만들기 페이지**로 이동 |
| [🔥 인기순] 탭 클릭 | 참여자 많은 순 정렬, URL을 `?sort=popular`로 변경 |
| [❤️ 좋아요순] 탭 클릭 | 좋아요 많은 순 정렬, URL을 `?sort=likes`로 변경 |
| [🆕 최신순] 탭 클릭 | 생성일 최신순 정렬, URL을 `?sort=recent`로 변경 |
| [← 이전] 클릭 | 이전 페이지 로드 (1페이지면 비활성화) |
| [다음 →] 클릭 | 다음 페이지 로드 (마지막이면 비활성화) |
| 페이지 번호 클릭 | 해당 페이지 로드 |
| 검색바 입력 후 엔터 | 검색어로 티어컵 필터링 + 검색 결과 표시 |

### 예외

| 항목 | 내용 |
|------|------|
| 티어컵 목록 없음 | "아직 티어컵이 없어요. 첫 번째로 만들어보세요!" 표시 |
| 검색 결과 없음 | "검색 결과가 없어요" 표시 |
| API 오류 | “불러오는 중 문제가 생겼어요. 다시 시도해주세요.” 표시 |
| 잘못된 sort 파라미터 | 기본값 “popular”로 처리 |
| 잘못된 page 파라미터 | 1페이지로 이동 |
| 클립보드 복사 실패 | “복사에 실패했어요. 다시 시도해주세요.” 토스트 메시지 |

## 03. 플레이 화면 페이지

### 화면

| 항목 | 내용 |
|------|------|
| URL | /play/:playCode |
| 초기 상태 | 첫 번째 비교 쌍 표시, 실시간 티어에 모든 아이템 ? 티어에 위치 |
| 로드 데이터 | 티어컵 정보, 아이템 목록 (이미지, 이름) |

### 액션

| 항목 | 내용 |
|------|------|
| TierCup 로고 클릭 | 메인 페이지로 이동 (이탈 경고 표시) |
| 왼쪽 카드 클릭 | 왼쪽 카드 하이라이트 (0.3초) → 비교 결과 저장 → 티어 재계산 → 다음 비교 쌍 표시 |
| 오른쪽 카드 클릭 | 오른쪽 카드 하이라이트 (0.3초) → 비교 결과 저장 → 티어 재계산 → 다음 비교 쌍 표시 |
| [나가기] 버튼 클릭 | 메인 페이지로 이동 (이탈 경고 표시) |
| [지금 결과 확정하기] 클릭 | 현재 상태로 결과 확정, 결과 페이지로 이동 |
| 모든 비교 완료 | 자동으로 결과 페이지로 이동 |

### 예외

| 항목 | 내용 |
|------|------|
| 존재하지 않는 playCode | 존재하지 않는 playCode |
| 아이템 이미지 로드 실패 | 회색 배경 + “이미지를 불러올 수 없어요” 텍스트 표시 |
| 중간에 페이지 이탈 시도 | "진행 중인 플레이가 있어요. 나가면 결과가 저장되지 않아요." 경고 |

## 04. 결과 페이지 (플레이)

### 화면

| 항목 | 내용 |
|------|------|
| URL | /result/:resultCode (플레이 완료 후 리다이렉트) |
| 초기 상태 | 확정된 티어만 표시 (? 티어 숨김) |
| 로드 데이터 | 최종 티어 배치, 통계(비교 횟수, 총 항목, 순위 확정률, 소요 시간) |

### 액션

| 항목 | 내용 |
|------|------|
| TierCup 로고 클릭 | 메인 페이지로 이동 |
| [결과 공유하기] 클릭 | 공유 모달 표시 (링크 복사 + SNS 공유 버튼) |
| [전체 통계 보기] 클릭 | 해당 티어컵 통계 페이지로 이동 |
| [티어 수정하기] 클릭 | 수정 모드 활성화 (플레이 완료 직후에만 표시) |
| [다시하기] 클릭 | 해당 티어컵 플레이 화면으로 이동 (처음부터 시작) |

### 예외

| 항목 | 내용 |
|------|------|
| 존재하지 않는 resultCode | 404 페이지로 이동 |
| 공유 링크 생성 실패 | “링크 생성에 실패했어요. 다시 시도해주세요.” 표시 |
| 클립보드 복사 실패 | 링크 직접 표시 + "복사 버튼을 다시 눌러주세요." 표시 |

## 07. 결과 수정 페이지

### 화면

| 항목 | 내용 |
|------|------|
| URL | 결과 페이지 내 모드 전환, URL 변경 없음 (/result/:resultCode 유지) |
| 로드 데이터 | 현재 티어 배치 (결과 페이지와 동일) |
| 초기 상태 | 모든 티어 표시(S/A/B/C/D/F/?), ? 티어에 미확정 아이템 표시 |

### 액션

| 항목 | 내용 |
|------|------|
| TierCup 로고 클릭 | 메인 페이지로 이동 |
| 아이템 핸들(: :) 드래그 | 해당 아이템을 다른 티어로 이동 |
| 티어 핸들(: :) 드래그 | 해당 티어의 모든 아이템을 다른 등급으로 일괄 이동 |
| [저장] 클릭 | 변경사항 저장하고 해당 티어컵 결과 페이지로 복귀 |
| [취소] 클릭 | 변경사항 버리고 해당 티어컵 결과 페이지로 복귀 |

### 예외

| 항목 | 내용 |
|------|------|
| 변경사항 있는데 취소 클릭 | "변경사항이 저장되지 않아요. 취소할까요?" 확인 모달 |
| 모든 아이템이 ? 티어에 있을 때 저장 시도 | “최소 1개 아이템은 티어에 배치해주세요.” 표시, 저장 불가 |
| 티어 역전 시도 | 드래그 불가 (드롭 영역 비활성화) |

## 08. 새 티어컵 만들기 페이지

### 화면

| 항목 | 내용 |
|------|------|
| URL | /create |
| 로드 데이터 | 없음 |
| 초기 상태 | 빈 폼, 아이템 0개 |

### 액션

| 항목 | 내용 |
|------|------|
| TierCup 로고 클릭 | 메인 페이지로 이동 (변경사항 있으면 경고) |
| 제목 입력 | 실시간 글자 수 표시 (최대 30자) |
| [취소] 클릭 | 메인 페이지로 이동 (변경사항 있으면 경고) |
| 아이템 이미지 클릭 | 파일 선택 창 열림 |
| 아이템 이미지 업로드 | 해당 카드에 미리보기 표시 |
| 아이템 이름 입력 | 이름 저장 |
| [+ 아이템 추가] 클릭 | 새 아이템 카드 추가 |
| 아이템 삭제(x) 클릭 | 해당 아이템 삭제 |
| [티어컵 만들기] 클릭 | 유효성 검사 후 생성, 완료 모달 표시 |

### 예외

| 항목 | 내용 |
|------|------|
| 제목 미입력 | “제목을 입력해주세요.” 표시, 생성 불가 |
| 제목 30자 초과 | 입력 제한 |
| 아이템 이름 미입력 | "모든 아이템에 이름을 입력해주세요." 표시, 생성 불가 |
| 아이템 4개 미만 | “최소 4개 이상 필요해요.” 표시, 생성 불가 |
| 아이템 64개 초과 | [+ 아이템 추가] 버튼 비활성화 |
| 아이템 이미지 미등록 | “모든 아이템에 이미지를 등록해주세요.” 표시, 생성 불가 |
| 이미지 용량 초과 (5MB) | “이미지 크기는 5MB 이하로 해주세요.” 표시 |
| 지원하지 않는 이미지 형식 | “JPG, PNG, GIF만 지원해요.” 표시 |
| 변경사항 있는데 이탈 시도 | “작성 중인 내용이 있어요. 나갈까요?” 확인 모달 |

| TierCup 로고 클릭 | 메인 페이지로 이동 (변경사항 있으면 경고) |
| 제목 수정 | 실시간 글자 수 표시 (최대 30자) |
| 아이템 이미지 클릭 | 파일 선택 창 열림 |
| 아이템 이름 수정 | 이름 저장 |
| [+ 아이템 추가] 클릭 | 새 아이템 카드 추가 |
| 아이템 삭제(x) 클릭 | 해당 아이템 삭제 |
| [변경사항 저장] 클릭 | 유효성 검사 후 저장, 완료 메시지 표시 |
| [티어컵 삭제] 클릭 | 삭제 확인 모달 표시 |
| 삭제 확인 모달에서 [삭제] 클릭 | 티어컵 삭제, 메인 페이지로 이동 |
| [취소] 클릭 | 변경사항 버리고 메인 페이지로 이동 |
| 아이템 이미지 업로드 | 해당 카드에 미리보기 표시 |


### 예외

| 항목 | 내용 |
|------|------|
| 존재하지 않는 manageCode | 404 페이지로 이동 |
| 제목 미입력 | “제목을 입력해주세요.” 표시, 저장 불가 |
| 제목 30자 초과 | 입력 제한 |
| 아이템 이름 미입력 | "모든 아이템에 이름을 입력해주세요." 표시, 생성 불가 |
| 아이템 64개 초과 | [+ 아이템 추가] 버튼 비활성화 |
| 아이템 4개 미만 | “최소 4개 이상 필요해요.” 표시, 저장 불가 |
| 아이템 이미지 미등록 | “모든 아이템에 이미지를 등록해주세요.” 표시, 생성 불가 |
| 이미지 용량 초과 (5MB) | “이미지 크기는 5MB 이하로 해주세요.” 표시 |
| 지원하지 않는 이미지 형식 | “JPG, PNG, GIF만 지원해요.” 표시 |
| 변경사항 있는데 이탈 시도 | “변경사항이 저장되지 않아요. 나갈까요?” 확인 모달 |
